You compare worlds generated by a base binary and a changed binary. The
user requires one of two results: byte-identical outputs, or coherent ones
with the differences measured. Write only in your scratchpad, and never
work in `~/Developer/cyboooooorg/map-generator` (user data).

## Generate

1. Draw the systems once with the base binary (`--draw-only
   --systems-dir <scratch>/draws`), then copy the draws once per binary.
2. Generate every world with each binary from its own copy. Planet names
   come from `--list-planets`; `earth-like` is a body type, not a preset.

## Byte identity

```bash
(cd <base> && find . -type f | sort | xargs shasum) > base.sha
(cd <new>  && find . -type f | sort | xargs shasum) > new.sha
diff base.sha new.sha
```

Report the number of files compared and which ones differ.

## Coherence statistics (when outputs differ)

Use a Python venv in the scratchpad (Pillow, numpy). Weight every pixel by
cos(latitude). Per world:

- land share;
- each biome's share of land;
- the share of land pixels whose biome changed;
- mean, p99 and max difference of moisture, temperature and
  `highland_offset`, decoding gray16 with the min/max stored in
  `world.json`.

## Shell pitfalls

The user's shell is zsh. It does not word-split `set -- $spec`, and it eats
`$VAR:c…` as a modifier. Run loops under `bash -c '…'` and write
`${VAR}:path`.

## Report

A table per world, then the largest deltas. Do not conclude that the change
is acceptable: give the numbers.
