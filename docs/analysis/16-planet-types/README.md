# Planet types: research notes

Working material behind the report [Known planet types](../16-planet-types.md)
(French version: [`16-planet-types.fr.md`](../16-planet-types.fr.md)).

The notes were written by research agents on 2026-11-15.

| File | Content |
|---|---|
| `classification_demographics.md` | Topic note: official definitions, mass and radius splits, occurrence rates |
| `rocky_planets.md` | Topic note: rocky planets, composition and regime |
| `sub_neptunes.md` | Topic note: sub-Neptunes, water worlds, radius valley |
| `giant_planets.md` | Topic note: giants, hot and ultra-hot Jupiters, super-puffs |
| `orbital_environment_types.md` | Topic note: rogue, circumbinary, pulsar, white dwarf and M dwarf planets |
| `verification_rocky_subneptunes.md` | Verification table for the rocky and sub-Neptune notes |
| `verification_giants.md` | Verification table for the giants note |
| `verification_environment_occurrence.md` | Verification table for the environment and occurrence notes |

The verification tables check the notes' claims against primary sources. Where
a table and a note disagree, the table supersedes the note. Several arXiv ids
recalled from memory in the notes were wrong; they were corrected in the
report, not in the notes, so rely on the report for identifiers.
