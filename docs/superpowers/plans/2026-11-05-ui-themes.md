# UI themes (PR T) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:executing-plans to implement this plan task-by-task. Steps
> use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Five selectable themes: Default (today's look), Holo HUD,
Orbital station, Cyberpunk and Military. Each restyles the interface
and the star view's neutral overlays, and keeps meaningful colours
fixed.

**Architecture:** Themes are data in `web/src/lib/themes.ts`, a map of
CSS custom properties per theme. `applyTheme` writes them on
`document.documentElement` and sets `data-theme`. `app.css` keeps
today's values as the default fallback and adds the decoration hooks:

- a frame clip path;
- a glow;
- the fonts;
- a `.hud` panel class;
- `[data-theme]` effects that are CSS only.

The star view reads its neutral overlay colours from the same tokens.

**Tech Stack:** Svelte 5, TypeScript, CSS custom properties, Google
Fonts, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-05-interface-redesign-design.md`
(section 6, and PR T in its plan of work).

## Global Constraints

- Default theme: pixel-identical to today. Its tokens equal `app.css`'s
  current values.
- Text contrast: at least 4.5:1 for `--text` and `--muted` on `--panel-solid`
  and `--bg` in every theme, and for `--accent-text` on `--accent`.
- Meaningful colours keep their hue in every theme:
  - the habitable zone, `#3fbf6f`;
  - the frost line, `#9cc8ff`;
  - velocity, `#9fe0ff`;
  - pull, `#ffa07a`;
  - map layers.
- No effect on the 3D canvas. Effects are CSS on the interface only.
- The theme is remembered in `localStorage` (try/catch), key
  `mapgen.theme`.
- Strings go in `lib/i18n` (en, fr). Fonts come from Google Fonts only.

## Review Focus

- A theme saved under an unknown name (an old or edited value) falls back
  to Default.
- Switching theme while a viewer is open recolours the star view's
  overlays without a reload.
- Long French labels in the theme picker fit.
- Private browsing, where storage throws: the app still starts, with
  Default.
- Military's green chrome next to the green habitable zone: the zone is
  still told apart.

### Task 1: Theme data and its contrast test

**Files:**

- Create: `web/src/lib/themes.ts`
- Create: `web/src/lib/themes.test.ts`

**Interfaces:**

- Produces:
  - `type ThemeName = 'default' | 'holo' | 'station' | 'cyberpunk' | 'military'`;
  - `THEMES: Record<ThemeName, ThemeTokens>`;
  - `THEME_NAMES: readonly ThemeName[]`;
  - `contrast(a: string, b: string): number`;
  - `loadTheme(): ThemeName`;
  - `saveTheme(name: ThemeName): void`;
  - `applyTheme(name: ThemeName): void`;
  - `overlayColours(): { orbit; selected; line; muted }`, read from the
    computed tokens;
  - `onThemeChange(listener): () => void`.
- `ThemeTokens` lists every token, with the `--` prefix:
  - `bg`, `panel`, `panel-solid`, `border`, `text`, `muted`, `accent`,
    `accent-text`, `link` and `danger`;
  - `control-bg`, `font-ui`, `font-display`, `radius`, `frame-clip`,
    `glow` and `label-bg`;
  - `overlay-orbit`, `overlay-selected`, `overlay-line` and
    `overlay-muted`.

  on `--bg`, and `--accent-text` on `--accent`, are all at least 4.5.
- [ ] Test: `loadTheme` falls back to `default` on an unknown value and
  when storage throws.
